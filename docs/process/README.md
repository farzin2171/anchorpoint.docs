# Process

How steps are written, reported and verified.

| Document | Purpose |
|----------|---------|
| [step-template.md](step-template.md) | Template for every `docs/steps/NN-<name>.md` (goal, starting state, changes, files, source mapping, resulting state, how to verify, decisions, known limitations) |
| [step-report-template.md](step-report-template.md) | The report sent after every step, before waiting for "next" |

Verification and review records (review trials, dual-mode verification, security scans) are added here
by the polish tasks.
